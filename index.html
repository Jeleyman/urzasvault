Open your vault

Import your Scryfall deck exports to browse everything you own, check whether you already have a card, and see what it’s worth.

You can pick several files at once, or drop them anywhere on this page.

On Scryfall, open a deck and export it as CSV. Import one file per deck: each file’s name becomes that deck’s name here, and importing a file with the same name later replaces that deck.
